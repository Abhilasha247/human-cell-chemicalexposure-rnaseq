# RNA-seq Chemical exposure Analysis 

## Overview

This project analyzes publicly available RNA-seq data from human cell lines exposed to different chemical treatments.

## Dataset

NCBI Gene Expression Omnibus (GEO)

Accession: GSE336490

Data source:
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE336490

## Research Question

Do different types of human cells respond differently to chemical exposure at the level of gene expression?

## Planned Analysis

I plan to use a two-way ANOVA to examine the effects of cell type and chemical exposure, including their interaction.

## Status

Project in progress.
